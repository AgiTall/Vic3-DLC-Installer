# Victoria 3 DLC Installer & Admin Builder

Удобный графический установщик DLC для Victoria 3 и приложение администратора (**VicAdmin**) для управления контентом, кастомизации интерфейса и генерации готовых автономных `.exe` установщиков.

---

## 🚀 Возможности

### 1. Установщик игры (генерируемый .exe)
- **Компактное окно 4:3 (640x480)** без лишних рамок Windows.
- **Интерфейс в стиле Victoria 3**: бордово-коричневые тона, полупрозрачная матовая панель слева с плавным размытием поверх арта.
- **Автоматический поиск игры**: установщик сам находит лицензионную Steam-версию Victoria 3 через системный реестр Steam и конфигурационные файлы библиотек (`libraryfolders.vdf`, App ID `529340`). Также доступен ручной выбор пути («Обзор»).
- **Анимация перехода при установке**: после нажатия «Установить» размытие плавно исчезает, открывая полный арт, а снизу отображаются индикатор прогресса, статус и элементы управления.
- **Управление процессом**: кнопки «Стоп» (пауза/продолжение) и «Отмена» с подтверждением действия.
- **Корректная замена файлов**:
  - Очищает старые папки `dlc` в корне игры и в `game/dlc`, после чего распаковывает актуальный DLC-пакет в обе директории.
  - Заменяет файлы проверки в `binaries/` без повреждения остальных файлов игры.

### 2. Приложение админа (VicAdmin.exe)
- **Кастомизация дизайна**: изменение названия актуального DLC, подзаголовка, описания, подписи автора, цвета заголовка и цвета акцентных кнопок.
- **Смена фонового изображения**: можно выбрать любой арт (`.jpg`, `.png`).
- **Интерактивный предпросмотр**: отображает внешний вид окна будущего установщика в реальном времени прямо в админке.
- **Менеджер контента**: добавление новых DLC, замена файлов проверки в `binaries`, удаление компонентов.
- **Генерация установщика в 1 клик**: собирает автономный исполняемый файл `.exe` (оболочка + сжатый архив контента), кэширует архив для мгновенной пересборки при смене только оформления.

## 🛠️ Сборка VicAdmin из исходников

Для сборки используется стандартный компилятор `csc.exe` (.NET Framework), встроенный в Windows. Дополнительных SDK ставить не требуется:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

После выполнения команды в корне появится `VicAdmin.exe`.

## 📦 Структура проекта

- `src/`
  - `Admin.cs` — интерфейс и логика админ-панели (VicAdmin).
  - `Installer.cs` — исходный код генерируемого установщика.
  - `Shared.cs` — алгоритмы размытия, композитинга фона и стилей.
  - `app.manifest` — манифест запроса прав администратора.
- `assets/` — фоновые изображения и ресурсы.
- `VicAdmin.exe` — готовое исполняемое приложение админа.
- `build.ps1` — скрипт быстрой компиляции VicAdmin.
